# 音声入力SOAPノート

ブラウザ標準の **Web Speech API** を利用し、マイクからの音声認識およびリアルタイムテキスト入力から、医療・介護・リハビリテーション記録の国際標準フォーマットである **SOAP（S:主観的情報, O:客観的情報, A:評価, P:計画）** へキーワードベースで自動振り分けを行うモダンWebアプリケーションです。

---

## 🌟 主な機能

1. **ワンクリック音声認識（録音開始 / 停止）**
   - ブラウザ標準の Web Speech API (`webkitSpeechRecognition` / `SpeechRecognition`) を使用。
   - 外部サーバーに音声データを送る追加ライブラリ不要で、セキュアかつ高速に動作。
   - 録音中はリアルタイムで中間認識結果が表示され、発話終了時に文章として確定します。
2. **手動テキスト編集・サンプル文章機能**
   - 音声認識されたテキストを直接修正・追記可能。
   - マイクが使えない環境や動作確認用に、ワンクリックで医療・リハビリの「サンプル文章」を自動入力・変換可能。
3. **高精度な文分割 & キーワードベースSOAP自動分類**
   - 句点（。）や改行などで文章を自動分解。
   - 文中のキーワードに応じて S / O / A / P および未分類へ即座に振り分け。
   - 判定の根拠となったキーワードをカード内で見やすくハイライト表示。
4. **充実の出力・共有機能**
   - 各セクション（S/O/A/P/未分類）ごとの個別クリップボードコピー。
   - カルテ全体を整形フォーマットで一括コピー。
   - テキストファイル（`.txt`）としてのローカル書き出し・ダウンロード保存。
5. **モダン & レスポンシブデザイン**
   - 白を基調としたクリーンで洗練されたUI。
   - S（青）、O（緑）、A（黄/アンバー）、P（赤）の色分けカード。
   - スマートフォン・タブレット・PCの画面サイズに最適化されたレスポンシブ表示。

## 📋 SOAP振り分けキーワードルール

| 分類 | 名称 | カードカラー | 該当キーワード例 |
| :--- | :--- | :--- | :--- |
| **S** | **主観的情報**<br>(Subjective) | 🟦 青 (Blue) | 「痛い」「つらい」「しびれる」「だるい」「動かしにくい」「不安」「眠れない」「訴え」など患者の自覚症状に関する文 |
| **O** | **客観的情報**<br>(Objective) | 🟩 緑 (Green) | 「ROM」「MMT」「度」「cm」「kg」「mmHg」「回」「秒」「歩行」「握力」「バイタル」「腫脹」「熱感」「発赤」など検査・測定値に関する文 |
| **A** | **評価・分析**<br>(Assessment) | 🟨 黄 (Yellow/Amber) | 「考えられる」「原因」「問題」「改善」「低下」「制限」「リスク」「評価」など分析・判断に関する文 |
| **P** | **計画**<br>(Plan) | 🟥 赤 (Red) | 「プログラム」「目標」「実施」「継続」「指導」「週」「回」「セット」「退院」「自主トレ」など治療計画に関する文 |
| **?** | **未分類**<br>(Unclassified) | ⬜ グレー (Gray) | 上記のキーワードに該当しなかった文 |

## 🚀 起動方法

### 方法1：ローカルHTTPサーバーで起動（推奨）
Chromium系ブラウザ（Chrome / Edge）ではマイクアクセスのセキュリティポリシー上、ローカルサーバー経由（`http://localhost:...`）での実行が推奨されます。

Pythonがインストールされている場合：
```powershell
cd C:\Users\tomo8\.gemini\antigravity\scratch\voice-soap-notes
python -m http.server 8080
```
起動後、ブラウザで [http://localhost:8080](http://localhost:8080) を開きます。

Node.js（npx）をご利用の場合：
```powershell
cd C:\Users\tomo8\.gemini\antigravity\scratch\voice-soap-notes
npx serve .
```

### 方法2：ブラウザで直接開く
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開くことも可能です。
※ 直接開いた場合でも手動テキスト入力や「サンプル文章を入力」によるSOAP変換機能は完全に動作します。マイク入力に関してはブラウザのセキュリティ設定により許可が必要となる場合があります。
